The Blindbox Diner

A high-novelty, social-first dining experience.

The Core Concept

The Mechanic

Customers purchase a mystery box at the entrance. Unboxing it reveals which of the 3 themed dining rooms they will eat in (e.g., Izakaya, Jazz Lounge, Malaysian Kopitiam).

The Offering

RM 45 per pax includes entry and a set meal tailored to the room's theme. Guests choose between 2 set options inside. Themes rotate quarterly to drive repeat visits.

Operational Realities: Flaws & Solutions

Flaw: Table Capacity Bottleneck. What if everyone unboxes the Izakaya room at once, leaving others empty and groups split up?

Solution: Group Unboxing & Live Weighted Gacha. One pull per table/group based on live availability. Add a "Trading Board" in the lobby so guests can trade tokens if they want a different room.

Flaw: Kitchen Complexity. Cooking 3 completely different cuisines requires massive kitchen overhead and staff.

Solution: Shared Ingredient Architecture. All sets use the same core proteins and carbs (e.g., chicken, rice, noodles) but are finished with room-specific sauces and plating styles.

Flaw: High Renovation Costs. Changing 3 rooms completely every quarter is too expensive.

Solution: Modular Ambience. Instead of building walls, use smart RGB lighting, projection mapping, music, and interchangeable table accessories to change themes overnight.

Financial Projections

Pricing Structure

  • Base Set Price: RM 45.00
  • Est. Final Group Checkout Price (per pax): RM 52.20 (utilizing a standard 1.16 multiplier to account for compounded service charge and tax).
  • Target Upsell: Themed mocktails/cocktails & desserts to push base spend to RM 65.00+ before tax.
  • Est. Food Cost: Keep base ingredients at 28-32% (RM 13.50 max per set) by unifying the kitchen prep line.
